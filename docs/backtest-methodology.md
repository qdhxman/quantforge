# 回测方法与已知局限

## 成交假设

| 项 | 设定 |
| --- | --- |
| 信号时点 | 第 `t` 根 K 线**收盘后**，只使用 `bars[0..t]` |
| 成交时点 | 第 `t+1` 根 K 线**开盘价** |
| 滑点 | 买入 `open×(1+slippage_bps/10000)`，卖出 `open×(1−slippage_bps/10000)` |
| 手续费 | `|成交金额| × commission_bps/10000`，双边收取 |
| 整手 | `lot_size`，默认 1（A 股可设 100） |
| 最小调仓 | `|目标市值 − 当前市值| < min_order_value` 时跳过，避免碎单 |
| 盯市 | 每根 K 线按收盘价计算权益 |
| 基准 | 四个标的等权、期初一次性买入并持有到期 |
| 分红/拆股 | **不处理**，请使用前复权数据 |
| 融券/借贷成本 | 不建模；`allow_short=false` 为默认 |

## 仓位映射

```
目标市值 = 组合权益 × 目标权重
Δ        = 目标市值 − 当前持仓市值
股数     = floor(|Δ| / 收盘价 / lot_size) × lot_size
```

股数还会被 `risk.max_order_notional` 提前截断。注意：**下单股数按 t 日收盘价估算，实际成交在 t+1 日开盘**，两者价格不同，因此实际仓位会与理论目标有小幅偏差——这是刻意保留的真实性，随后由每 bar 的再平衡逐步修正。

买入前会再过一遍完整风控（购买力、单票仓位、总敞口、熔断、冷却等），所以在回测里也能看到「策略想买但被风控拦下」的记录，与实盘一致。

## 防未来函数的三道保障

1. 因子函数签名只接受 `bars` 和当前下标 `i`，实现里只读 `bars[:i+1]`；测试 `test_no_lookahead` 会把未来 K 线改成极端值，断言历史信号与成交完全不变。
2. 信号引擎的 EMA 平滑 / 方向滞后状态按 bar 顺序推进，不做全序列预计算。
3. 决策与成交在 `backtest.py` 里是两段分离的循环：`pending` 队列在收盘时写入、在下一根开盘时消费。

## 绩效指标

| 指标 | 定义 |
| --- | --- |
| 总收益 | `期末权益/期初资金 − 1` |
| CAGR | `(期末/期初)^(252/收益序列长度) − 1` |
| 年化波动率 | 日收益总体标准差 × √252 |
| 夏普 | `日均收益/日收益标准差 × √252`（无风险利率按 0 处理） |
| 索提诺 | 下行标准差口径（负收益平方和 / 全部样本数），× √252 |
| 最大回撤 | 权益相对历史峰值的最小跌幅 |
| Calmar | `CAGR / |最大回撤|` |
| 胜率 | 有已实现盈亏的平仓单中盈利占比 |
| 盈亏比 | 盈利总额 / 亏损总额绝对值 |
| 因子贡献度 | 回测期内各因子 `|weight × score|` 的累计占比（**话语权，不是盈利能力**） |

## 已知局限（认真读）

- **单资产路径依赖**：本引擎是多标的组合回测，但没有行业/市值中性化、没有因子正交化、没有换仓约束优化。
- **成交过于理想**：市价单按开盘价全额成交，不建模盘口深度、部分成交、涨跌停、停牌、T+1、集合竞价。
- **成本简化**：只含线性手续费与滑点，不含印花税、融资利率、借券费、冲击成本随规模上升。
- **样本内**：仓库自带的合成行情只有一个固定随机种子，任何「好参数」都是对这段路径的过拟合。真实研究必须做样本外/滚动窗口/多种子稳健性检验。
- **无生存偏差处理**：接入真实数据时需自行处理退市、更名、成分股变更。
- **不构成策略有效性证明**：回测框架正确 ≠ 策略有效。

## 复现与交叉验证

```bash
python scripts/verify_parity.py                 # Python 基准（使用 momentum.json + seed 20260101）
node scripts/verify_parity.js                  # 浏览器引擎逐项比对
```
